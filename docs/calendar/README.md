# Academic Flow

This page keeps the **public academic progression** of the course. Exact section schedules, deadlines, grading rules, rooms, and exam logistics remain in the official course documents and announcement channels.

## Five learning blocks

The course material is organized around five coherent blocks:

1. **Bayesian Classifiers · Risk Minimization · Decision Boundaries · Naive Bayes**
2. **MLE · Optimization · Logistic, Linear & Non-Linear Regression**
3. **Decision Trees · SVM · Kernels · model comparison**
4. **Neural Networks · PCA/LDA · Feature Selection**
5. **Clustering · Mixture Models · Expectation-Maximization (EM)**

Each block feeds into the corresponding assignment and quiz material when released.

## Shared release principle

Whenever feasible, the graduate and undergraduate sections use **one shared public assignment/project release**. Graduate-only questions or advanced requirements are clearly marked inside that same file rather than maintaining duplicate public copies.

## High-level semester journey

| Stage | Focus |
|---|---|
| **Foundations** | Data, Bayesian decision making, risk, Naive Bayes |
| **Estimation & optimization** | MLE, optimization, regression models |
| **Classical discriminative models** | Trees, SVM, kernels, model comparison |
| **Representation & neural models** | Neural Networks, PCA/LDA, feature selection |
| **Unsupervised learning** | Clustering, mixture models, EM |
| **Synthesis** | Final project, review, and released exam material when appropriate |

This public view is intentionally schedule-agnostic so the material remains useful beyond a single classroom timetable.
