# Final Project

The course final project is organized in **three phases** and culminates in an oral defense.

| Phase | Public folder | Status |
|---|---|---|
| Phase 1 | [`phase-1/`](phase-1/) | Not released |
| Phase 2 | [`phase-2/`](phase-2/) | Not released |
| Phase 3 | [`phase-3/`](phase-3/) | Not released |

Each phase folder will contain the approved description, starter material, deliverable requirements, and public clarifications.

Every team member is expected to understand the complete project. Individual scores may differ based on demonstrated understanding and contribution during the defense.
