## Assessment Alignment

Each `Quiz i` corresponds to the same syllabus block as `HW i`. If a student's score on a quiz falls below the **announced numerical quiz cutoff**, the normalized quiz score mapped to the **1-point assignment scale** replaces the score of the corresponding assignment. The exact numerical cutoff is announced through official course channels.

## Submission Standard

- Theory answers should be concise, complete, and readable.
- Programming work is submitted as a reproducible **`.ipynb`** notebook unless stated otherwise.
- A grader should be able to run the notebook from top to bottom without editing the submitted code.
- **Graduate ML:** each assignment may include **one or two additional advanced questions**, including questions from graduate-only material.
- **Introduction to ML:** graduate-only advanced questions are not required.
- The approved course description and eLearn announcements are authoritative for grading and deadline rules.

**Important:** The current assessment policy assumes **in-person delivery**. If the course moves online or the teaching mode changes materially, quiz/exam mechanics and related rules may be revised by the instructors.

**Public-release boundary:** Public folders contain release material only. Solutions, private rubrics, grading notes, and student submissions are never stored here before an authorized public release.
