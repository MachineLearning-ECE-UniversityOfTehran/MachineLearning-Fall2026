## Shared Handout Design

Whenever feasible, both sections receive **one shared assignment handout**. Graduate-only questions are clearly marked inside that same file, typically as the final advanced question(s), instead of maintaining two nearly identical public copies.

## Submission Standard for Programming Material

- Programming work should be reproducible in **Python 3 / Jupyter**.
- Starter notebooks, datasets, and supporting files are published alongside the relevant assignment when needed.
- A released notebook should be runnable from top to bottom without hidden local dependencies.

**Public-release boundary:** Public folders contain released learning material only. Solutions, private rubrics, grading notes, and student submissions are not stored here before an authorized public release.
