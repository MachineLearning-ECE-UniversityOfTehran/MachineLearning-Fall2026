# Assignments

The course includes **five individual assignments**. Each released assignment folder may contain:

```text
HWx/
├── ML-HWx.pdf
├── ML-HWx-Starter.ipynb      # when applicable
├── data/                     # when applicable
└── README.md                 # release notes / public clarifications
```

Assignment policy, late rules, submission format, and any graduate-only advanced question are defined by the approved course description and the specific assignment statement.

Unreleased solutions and private rubrics must not be stored in this public repository.
