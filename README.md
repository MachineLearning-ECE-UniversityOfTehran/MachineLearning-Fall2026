## Syllabus

1. Introduction to Machine Learning Concepts
2. Introduction to Data
3. Bayesian Classifiers
4. Risk Minimization and Decision Boundaries
5. Naive Bayes
6. Maximum Likelihood Estimation (MLE)
7. Optimization
8. Logistic Regression
9. Linear Regression
10. Non-Linear Regression
11. Decision Trees
12. Support Vector Machines (SVM)
13. Neural Networks
14. Principal Component Analysis (PCA) and Linear Discriminant Analysis (LDA)
15. Feature Selection
16. Clustering

The exact pacing may change during the semester. The official calendar and eLearn announcements take precedence over this overview.

## Assignments & Reproducibility

Assignments may include theoretical and practical/programming questions. Public assignment packages will be published under [`assignments/`](assignments/).

Programming submissions are expected to be reproducible in **Python 3 / Jupyter**: a grader should be able to run a notebook from top to bottom and reproduce its outputs without modifying the submitted code.

Graduate students may receive additional advanced questions as specified in each assignment release. The approved course description is the authoritative source for grading and submission policy.

---

## Final Project

The final project is organized in **three phases**. Public phase descriptions, starter material, and submission guidance will be published under [`project/`](project/).

The project culminates in an oral defense. Every team member is expected to understand the complete project, and individual scores may differ according to demonstrated understanding and contribution.

---

## Academic Integrity

The official course description and university regulations govern academic integrity. In particular, students must understand and be able to explain the work they submit, including AI-assisted text, derivations, or code.

The public repository intentionally excludes unpublished solutions, private rubrics, grades, student data, and staff-only material.

---

## Repository Workflow

This is the **public/student-facing repository**. Draft solutions, grading rubrics, answer keys, student records, and unreleased assessment material must remain in a separate private staff workspace.

Course staff should use branches and pull requests for substantive changes. See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the release workflow and review checklist.
